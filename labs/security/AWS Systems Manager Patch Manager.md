# AWS Systems Manager Patch Manager

## Overview

This lab focused on using **AWS Systems Manager Patch Manager** to manage operating system patching across Amazon EC2 instances. The primary objective was to patch Linux instances using a default patch baseline, create a custom Windows patch baseline, associate it with a patch group, and verify patch compliance.

The lab demonstrated how Patch Manager can establish patching policies, target managed instances using tags, install approved patches, and monitor compliance across an EC2 environment.

---

## Task 1: Patch Linux Instances Using Default Baselines

Used the AWS-provided default patch baseline to scan and install patches on the Linux EC2 instances.

Key activities completed:

* Accessed the pre-configured EC2 instances through AWS Systems Manager Fleet Manager.
* Reviewed the Linux instances and their Systems Manager configuration.
* Opened Patch Manager and initiated a patching operation.
* Used the `AWS-AmazonLinux2DefaultPatchBaseline` baseline.
* Configured the operation to **Scan and install**.
* Selected **Reboot if needed**.
* Targeted instances using the `Patch Group` tag.
* Used the `LinuxProd` patch group value.
* Monitored the patching operation and verified successful completion.

Skills demonstrated:

* AWS Systems Manager Patch Manager
* EC2 patch management
* Default patch baselines
* Instance targeting using tags
* Linux patching
* Patch compliance concepts

---

## Task 2: Create a Custom Windows Patch Baseline

Created a custom patch baseline for the Windows Server 2019 instances.

Key activities completed:

* Created a custom patch baseline named `WindowsServerSecurityUpdates`.
* Selected **Windows** as the operating system.
* Configured `WindowsServer2019` as the product.
* Created approval rules for **Critical** and **Important** security updates.
* Configured both rules for the `SecurityUpdates` classification.
* Set automatic approval to **3 days**.
* Configured compliance reporting for the selected severity levels.
* Associated the custom baseline with the `WindowsProd` patch group.

Skills demonstrated:

* Custom patch baseline creation
* Patch approval rules
* Windows patch management
* Security update classification
* Patch group association
* Systems Manager configuration

---

## Task 3: Tag and Patch Windows Instances

Applied the custom patch group to the Windows EC2 instances and used Patch Manager to perform the patching operation.

Key activities completed:

* Added the `Patch Group` tag to Windows-1, Windows-2, and Windows-3.
* Set the tag value to `WindowsProd`.
* Configured Patch Manager to target instances using the `Patch Group` tag.
* Selected **Scan and install** as the patching operation.
* Selected **Reboot if needed**.
* Started the patching operation.
* Reviewed the execution through Systems Manager.
* Inspected the Run Command output generated by Patch Manager.
* Verified `PatchGroup : WindowsProd` in the patch operation output.
* Confirmed that the custom `WindowsServerSecurityUpdates` baseline was being used.

The patch operation successfully installed patches and reported zero failed patches.

Skills demonstrated:

* EC2 tagging
* Patch group targeting
* Windows patch installation
* Systems Manager Run Command
* PatchBaselineOperations
* Patch operation monitoring

---

## Task 4: Verify Patch Compliance

Verified the patch compliance status of all managed EC2 instances.

Key activities completed:

* Opened the Patch Manager compliance reporting dashboard.
* Reviewed compliance information for all six EC2 instances.
* Verified that the three Linux instances were compliant.
* Verified that the three Windows instances were compliant.
* Confirmed that the Windows instances used the custom baseline `pb-0dc393e0afb80fae5`.
* Confirmed that the Linux instances used the default baseline `pb-0e930e75b392d70da`.
* Reviewed security non-compliant counts and available security updates.
* Verified the last patch operation date.

The final compliance report showed **6 out of 6 instances as Compliant**.

Skills demonstrated:

* Patch compliance monitoring
* Compliance reporting
* Baseline verification
* Security update monitoring
* Systems Manager reporting
